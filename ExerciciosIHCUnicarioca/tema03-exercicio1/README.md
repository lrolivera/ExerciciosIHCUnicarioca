# Tema 03 – Exercício 1: Página de apresentação de um produto

Programação Web Front-End (IHC) – Unicarioca

Página feita com **Bootstrap 5** usando container, grid, tipografia, cores e classes utilitárias.

## Estrutura

```
tema03-exercicio1/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── img/
    └── produto.svg
```

## Como abrir
Abra o `index.html` no navegador (precisa de internet para carregar o Bootstrap pelo CDN).
