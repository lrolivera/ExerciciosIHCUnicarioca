# Tema 04 – Primeiro projeto com jQuery

Programação Web Front-End (IHC) – Unicarioca

Página simples com jQuery que:
- altera o texto de um parágrafo ao clicar em um botão;
- mostra e esconde um texto secreto com dois botões.

## Estrutura

```
tema04-exercicio1/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

## Como abrir
Abra o `index.html` no navegador (precisa de internet para carregar o jQuery pelo CDN).
