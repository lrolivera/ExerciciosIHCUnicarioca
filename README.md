🎯 Sobre o projeto

Neste repositório ficam os exercícios guiados da disciplina, um por pasta, do jeito mais simples possível, para aprender cada conceito passo a passo. Cada exercício tem seu próprio index.html, css/ e js/.

🗂️ Exercícios
Tema	Pasta	O que foi feito	Tecnologia
03	tema03-exercicio1	Página de apresentação de um produto com container, grid, tipografia e cores	Bootstrap 5
03	tema03-exercicio2	Mini cartão de perfil com fundo colorido, foto redonda e classes utilitárias	Bootstrap 5
04	tema04-exercicio1	Botões que alteram um texto e mostram/escondem um conteúdo	jQuery
06	tema06-exercicio1	Nome em tempo real, lista de tarefas e contador de cliques	React (useState)
07	tema07-exercicio1	Componente Saudacao com mensagem personalizada pelo nome digitado	React (props)

▶️ Como rodar

Pelo navegador (recomendado) Acesse: https://lrolivera.github.io/ExerciciosIHCUnicarioca/

No seu computador

Clone o repositório:
bash
   git clone https://github.com/lrolivera/ExerciciosIHCUnicarioca.git
Abra a pasta no VS Code.
Clique com o botão direito no index.html → Open with Live Server.

⚠️ Os temas 06 e 07 usam o Babel para ler o arquivo js/app.js, por isso precisam de um servidor (GitHub Pages ou Live Server). Abrir o index.html com duplo clique não funciona para eles. Os demais abrem normalmente.

💡 O que cada tema ensina
Tema 03 – Bootstrap: container, row, col-md-6, text-primary, display-4, bg-light, p-4, img-fluid e outras classes utilitárias.
Tema 04 – jQuery: $(function(){}), seletores por #id, .click(), .text(), .show() e .hide().
Tema 06 – React: JSX, useState, onChange, onClick e .map() para listas.
Tema 07 – React: componentes funcionais, props e renderização condicional com if/else.
